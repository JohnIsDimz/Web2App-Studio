Cara Beli Token

  1. Top up saldo dulu di menu Deposit (kalau belum)
  2. Pilih nominal token yang mau dibeli (min Rp 500)
  3. Klik BELI TOKEN — saldo langsung dipotong, token langsung masuk
  4. Token tidak pernah kadaluarsa — bisa dipakai kapan saja
  5. Rate tetap: 1 token = Rp 500 — tidak ada biaya tersembunyi
